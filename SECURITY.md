# Security

Please report a suspected vulnerability privately through [Report a vulnerability](https://github.com/Vesta-Software-Group/vesta-companion/security/advisories/new). Do not include credentials or live work data. Describe the affected version, a fictional reproduction and the likely impact.

For general setup questions and feature ideas, use the repository's public issues with fictional examples only.

This project is a beta. Security fixes target the newest published beta; earlier downloads remain available for traceability. Read release notes before updating and preserve personal/ in a separate private location.

The [security model](docs/SECURITY.md) explains the app-enforced access boundaries, original core code, skill review and task-file safeguards. Instructions guide an agent; they are not a sandbox or security certification.
