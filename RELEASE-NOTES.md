# Vesta Companion v1.1.0

More useful everyday workflows, with the same download, unzip and open-folder setup.

- Adds 12 skills: inbox triage, email drafting, Teams catch-up, persona reviews, weekly reporting, retrospectives, GitHub support, decision decks, relationship and commitment retrieval, governed improvement, local quality checks and software development guidance.
- Includes templates for audience simulations, approved report candidates, weekly reports, commitments and optional routines. Routines remain off until configured in an approved app.
- Expands the Vesta HTML/PDF guide with practical prompts, capture choices and a simple v1.0 upgrade route.
- Makes session-only handling explicit. Email stays draft-only; connected briefings and catch-ups are read-only. Simulated audience reactions are labelled as assumptions, never real feedback.
- Keeps the existing personal/ layout, task JSON format and dependency-free core. No legacy workspace, developer runtime or framework installation is added.

## Updating from v1.0.0

Download **vesta-companion.zip** from this release's **Assets**, extract into a separate new folder, and ask your existing assistant to copy and verify your complete **personal/** folder. Keep the old folder intact. No format migration is required. See docs/UPDATING.md before switching.

## Validation and limits

The release receives local persistence/upgrade tests, browser checks, skill/reference review and PDF inspection. New instruction workflows are not a claim of live model or Microsoft 365 connector certification; access still depends on your approved app and company permissions. Detailed evidence is in docs/TESTING.md.
