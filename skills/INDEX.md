# Core skills

Ask naturally. Read the matching canonical skill when the task calls for it.

| Skill | When to use it |
|---|---|
| [companion-care](companion-care/SKILL.md) | Help with backup, recovery, safe updates, connection checks and optional schedules. Use when the user asks to back up, move apps, upgrade or schedule briefings. |
| [companion-contacts](companion-contacts/SKILL.md) | Maintain a professional contact book and retrieve relationship context. Use to remember a contact, prepare for a conversation or find previous commitments. |
| [companion-daily-brief](companion-daily-brief/SKILL.md) | Create a daily briefing from Outlook email, Outlook calendar, Microsoft Teams and local priorities. Use for morning briefs, daily catch-ups or a review of today's commitments. |
| [companion-decision-deck](companion-decision-deck/SKILL.md) | Create a self-contained HTML executive decision deck from selected evidence. Use for decision meetings and concise leadership alignment materials. |
| [companion-development](companion-development/SKILL.md) | Plan or implement a bounded software change in the selected project, with reviewable edits, appropriate tests and explicit release scope. |
| [companion-email](companion-email/SKILL.md) | Draft an email from a selected message or supplied context. Use for replies and new email wording; never sends or creates a connector draft. |
| [companion-github](companion-github/SKILL.md) | Inspect a selected GitHub repository or prepare an issue, PR or review draft using existing approved access. External writes require exact approval. |
| [companion-improvement](companion-improvement/SKILL.md) | Propose and test an improvement to a personal skill or standing preference without unchecked self-modification. |
| [companion-inbox](companion-inbox/SKILL.md) | Review a bounded Outlook inbox without changing the mailbox. Use for email triage, priorities and follow-up identification. |
| [companion-memory](companion-memory/SKILL.md) | Remember and recall preferences, decisions, knowledge and progress from local files. Use when the user asks to remember, retrieve context, resume work or switch apps. |
| [companion-personas](companion-personas/SKILL.md) | Stress-test a draft, plan or decision with owner-authored simulation personas. Use for audience-perspective reviews, never impersonation or real feedback. |
| [companion-planning](companion-planning/SKILL.md) | Prioritise work, make plans and maintain the local to-do list and HTML board. Use when the user supplies tasks, asks what to do next, or wants to update their board. |
| [companion-projects](companion-projects/SKILL.md) | Plan and track small projects with milestones, decisions and next actions. Use to start a project, review progress, resolve blockers or produce a project update. |
| [companion-quality](companion-quality/SKILL.md) | Check local assistant files, task data, skill discovery and privacy boundaries without repairing them automatically. |
| [companion-relationships](companion-relationships/SKILL.md) | Retrieve relationships and unresolved commitments from source-linked local notes. Use for who promised what, relationship timelines and linked decisions. |
| [companion-retrospective](companion-retrospective/SKILL.md) | Capture outcomes, corrections and reusable lessons from a bounded piece of work without silently changing assistant behaviour. |
| [companion-review](companion-review/SKILL.md) | Prepare for meetings and run a weekly review from local notes and optional approved sources. Use for meeting preparation, end-of-week reflection or open-commitment reviews. |
| [companion-setup](companion-setup/SKILL.md) | Guide first-time setup and customise the assistant name, profile, language and preferences. Use on first use or when the user asks to set up or personalise Companion. |
| [companion-skill-create](companion-skill-create/SKILL.md) | Create or improve a personal reusable skill from a user's workflow. Use when the user asks to teach the assistant a repeatable process or add a custom skill. |
| [companion-teams](companion-teams/SKILL.md) | Summarise selected Teams chats or channels over a bounded period without posting or changing Teams. |
| [companion-weekly-report](companion-weekly-report/SKILL.md) | Capture approved weekly-report candidates and draft a chief-of-staff report. Use for weekly outcomes, decisions, risks and support requests. |

Read personal/skills/INDEX.md when present. Personal skills retain their own review status.
