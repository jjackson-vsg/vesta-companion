# Quality

Read system/COMPANION.md first.

1. Confirm the selected local kit and keep the check read-only. Do not install tools, initialise a profile or run an update merely to inspect health.
2. Compare AGENTS.md and CLAUDE.md, canonical skills and their wrapper/index references. Check whether profile and handover exist; absence before setup is normal.
3. If the optional Python helper is already available, validate task schema with its read/validation functions without rendering or importing. Otherwise inspect with native file tools and state the limitation. A board file is not proof that its latest edits were saved.
4. Check task/commitment contradictions, unsupported connector claims, duplicate scheduler ownership and accidental private output outside personal/. Do not echo secret-like matches; report only affected paths and safe categories.
5. Report pass/fail/not-configured/not-tested with evidence and suggested fixes. Do not repair, delete, back up, commit, push or change permissions during this check.
