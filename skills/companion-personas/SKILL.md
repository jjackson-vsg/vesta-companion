# Personas

Read system/COMPANION.md first.

1. Use an owner-supplied or owner-selected simulation profile and a bounded draft, plan or decision. Use templates/persona.md when the owner requests a new profile.
2. Check purpose, assumptions, source class, limitations and review date. Do not create a real-person psychological profile, infer sensitive traits or present a simulation as anyone's actual views.
3. Identify likely questions, confusion, objections, risks and improvements, explicitly labelled as inferences from the profile assumptions.
4. Keep profiles separate; do not call agreement between simulated profiles real consensus or user research.
5. Default to review in chat. Persist a profile or review only at the owner's request, under personal/vault/personas or personal/outputs/persona-reviews, keeping earlier versions. Do not edit the source draft or send anything automatically.
