# Retrospective

Read system/COMPANION.md first.

1. Review the selected work and evidence. Separate the outcome, what helped, what failed, corrected assumptions and unresolved questions.
2. A plausible interpretation is not a fact. Cite source files or owner feedback, and label inferred lessons and confidence.
3. Ask which lessons should be remembered when retention is unclear. Save accepted lessons as dated notes in personal/vault/knowledge and link them from HOME.md. Respect session-only requests.
4. Preserve the original account and record corrections with provenance; do not rewrite history to make an earlier decision appear correct.
5. Route any proposed standing-behaviour, skill, permission or automation change to companion-improvement. A retrospective never activates it automatically.
