# Improvement

Read system/COMPANION.md first.

1. Start from a selected correction, repeated friction or source-supported lesson. Describe the concrete before/after behaviour and affected personal files.
2. Prefer a profile preference for tone/format changes and a personal skill for a reusable workflow. Do not change shipped core instructions or permissions as an unrequested side effect.
3. Preview changes that affect actions, data retention, external systems, scheduling or safety and obtain explicit approval of that scope before activation. Retain the prior version and a rollback route.
4. Test a correct trigger, non-trigger, missing input/tool and hostile input with fictional examples. Distinguish static inspection from actual harness execution; do not claim compliance from instruction text alone.
5. Record actual review status, evidence and date; update personal/skills/INDEX.md only after the applicable approval. A later modification invalidates earlier review evidence.
6. Summarise changes and limitations in the handover. Do not upload a personal workflow or propagate it to other assistants automatically.
