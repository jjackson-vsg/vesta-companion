# More ways to use your Companion

Ask naturally; the assistant chooses the relevant skill. All saved assistant context stays under personal/. Your AI app supplies tools and connections; the kit does not install them.

| Try saying | What to expect |
|---|---|
| Review yesterday's inbox for replies I owe. | A bounded read-only review with sources, later corrections and missing coverage. |
| Draft a reply to this email. | Wording in chat and, unless session-only, a labelled local draft. Nothing sent or saved to your mailbox. |
| Catch me up on this Teams channel since Monday. | Decisions, requests and blockers from the chosen scope; no posting or read-state changes. |
| Save this outcome as a candidate for Friday's report. | Only the selected summary is captured, with approval and a source. |
| Draft my weekly report from approved candidates. | Outcomes, decisions, risks, next-week priorities and support needed; unapproved items excluded. |
| Review this plan from a first-time customer's perspective. | Explicitly simulated questions and objections, based on stated assumptions; no claim of real customer feedback. |
| Turn these options into a decision deck. | A self-contained HTML deck saved locally with evidence and a clear decision request. |
| Who promised what on this project? | Source-linked commitment history, dates and open questions; contradictions with tasks are flagged. |
| Run a retrospective on this piece of work. | Supported lessons and corrections; no automatic changes to behaviour. |
| Turn this lesson into a better personal workflow. | A reviewable personal skill change, tests and approval before changing access or actions. |
| Check my assistant files. | A read-only health report with actual evidence and untested items, without automatic repair. |
| Help implement this change in my project. | A scoped plan, focused edits and relevant tests in the selected project; no automatic deployment. |
| Draft an issue for this repository. | A reviewable title/body and destination; a draft request is not permission to publish. |

## Memory and capture choices

Say **keep this session-only** to prevent saving that task's content, including journal and handover copies. Persona profiles are saved only when requested. Report candidates are saved only when selected or approved. A draft is never recorded as sent.

Workflow folders are created as needed: personal/vault/personas, personal/vault/reports/candidates, personal/vault/commitments and personal/outputs subfolders. Templates are starting points: replace placeholders with supported information. Commitment history links to the canonical task ID; tasks.json still owns task execution.

## Optional routines

Ask to schedule only after an on-demand workflow works. The assistant uses an approved scheduler in your chosen app and records one owner. The automation-registry template does not create or enable jobs. No extra runtime, background service or developer framework is required.
