# Visual identity

Original Vesta Companion wordmark treatments and layouts use Vesta's publicly visible navy (#143c55, #295c83) and yellow (#dfc102) palette as observed on the public website on 2026-09-09. No private brand files, commercial fonts, copied artwork or embedded corporate documents are included. Typography uses system fonts.
